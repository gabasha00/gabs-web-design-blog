Blog Setup, My Process

  • 10 February 2026

To be honest, at first I really had no clue what I wanted for this page. I was looking at inspiration on blog sites but still had no clue. I started to draft out some basic plans in my sketch book:

After I sketched this out, I just figured I would make something visually easy to navigate but still tailored towards my own aesthetics. I want somebody to know that this is a website that showcases my work / projects without being looking too convoluted, so more on the portfolio side.

While working on the layout, I had to look at most of the code and use the console to get used to the base code and figure out what exactly I'd need to change the most to get the desired look for what I wanted. I realized most of my editing for the home page would be happening for the .nav class in the index.css and the header and footer.

To help navigate the type of styling I'd need to initially edit to create a side navigation bar, I used this page to help. From there, I tweaked the image size and font sizes to what I needed.

I'm still figuring out how to edit the CSS so that the individual post tags all have styling!
