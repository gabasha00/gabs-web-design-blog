# Project Design and Inspiration #

Whilst working with Ivy and Kylah, initially we had some trouble figuring out what the exact idea was for our project. We knew a general concept, but eventually got everything together, which  was this:

This general story behing our project, is that this automous computer, "Mutha" has been stranded in space for some time after a mission gone wrong killed its crew. It now floats across space aimlessly. This is the first time it has come in contact with a human (the user) in years. It wants the user to explain to it the meaning of man.

# My Role #

In this project, my role was mostly the front-end and UI design, whilst also assisting in some of the backend code as well as the code for the mapping. I created the landing screen animation and illustration of the space ship, as well as the designs for the buttons, popups, and some of the form features. I used and created JS functions from previous personal projects of mine to enhance some of the dynamics of the interface.

# Challenges #

As you might see on Kylah or Ivy’s posts, we definitely had the most challenge utilizing Github and making sure all changes and contributions to the main branch were smoothly integrated. I personally had a significant challenge making sure the landing page layout ran smoothly and that everything stayed in place, but in the end I figured out what I felt would best work for the site.
